# 拾光快捷工具（macOS）

电脑端以菜单栏应用运行，包含快捷启动与剪切板同步两部分。

## 快捷窗口

- 双击 Command 打开（首次使用需授予“辅助功能”权限）
- 输入数学表达式即时计算，回车复制结果
- 输入中文或英文应用名称搜索，上下键选择、回车启动
- 输入 `fy ` 加中文或英文进行互译，回车复制结果

翻译使用无需账号的公共服务，需要联网；服务不可用时会在结果区提示。

## 剪切板同步

应用通过 Bonjour 自动出现在同一局域网中。手机无需填写电脑 IP、端口或密钥，打开“剪切板共享”开关即可自动连接；局域网不可用时使用配置的 MQTT 服务。

## 使用

1. 打开 `拾光快捷工具.app`，菜单栏会出现应用图标。
2. 确保 Mac 和 Android 手机连接同一个 Wi-Fi。
3. 在手机“拾光 → 剪切板共享”中打开开关。

macOS 首次接收网络连接时可能询问是否允许，选择允许即可。连接状态可在菜单栏图标中查看。

## 构建

```bash
zsh scripts/package_app.sh
```

应用生成在 `dist/拾光快捷工具.app`。电脑身份密钥保存在 `~/.ez-clipboard/config.json`，仅供程序自动验证设备身份，不需要用户查看或配置。

## 当前范围

- 仅同步纯文本，单条最多 256 KB
- 局域网优先，MQTT 作为跨网络回退渠道
- 连接使用 X25519 协商密钥，正文使用 AES-256-GCM 加密
- 未连接时才进行局域网发现，连接后停止扫描
- 菜单栏“共享历史”可复制或收藏；收藏置顶，未收藏最多保留 100 条
- 暂不自动登录启动
