# 拾光剪切板（macOS）

电脑端以菜单栏应用运行，通过 Bonjour 自动出现在同一局域网中。手机无需填写电脑 IP、端口或密钥，打开“剪切板共享”开关即可自动连接。

## 使用

1. 打开 `拾光剪切板.app`，菜单栏会出现双矩形图标。
2. 确保 Mac 和 Android 手机连接同一个 Wi-Fi。
3. 在手机“拾光 → 剪切板共享”中打开开关。

macOS 首次接收网络连接时可能询问是否允许，选择允许即可。连接状态可在菜单栏图标中查看。

## 构建

```bash
zsh scripts/package_app.sh
```

应用生成在 `dist/拾光剪切板.app`。电脑身份密钥保存在 `~/.ez-clipboard/config.json`，仅供程序自动验证设备身份，不需要用户查看或配置。

## 当前范围

- 仅同步纯文本，单条最多 256 KB
- 单台 Android 设备
- 仅同一局域网
- 连接使用 X25519 协商密钥，正文使用 AES-256-GCM 加密
- 未连接时才进行局域网发现，连接后停止扫描
- 菜单栏“共享历史”可复制或收藏；收藏置顶，未收藏最多保留 100 条
- 暂不自动登录启动
